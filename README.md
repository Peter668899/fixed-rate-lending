# Fixed-Rate Lending

固定利率超额抵押借贷协议。

## 核心机制
- **pToken / jToken 双凭证计息**：pToken 代表本金凭证，jToken 代表计息/收益凭证，利息按区块时间线性累积。
- **超额抵押与抵押率**：借款需超额抵押，抵押率 = 抵押品价值 / 负债，低于阈值进入风险区。
- **健康因子（Health Factor）**&#8203;：HF =（抵押品价值 × 清算阈值）/ 负债；HF < 1 触发清算。
- **清算触发与风险参数**：清算罚金、清算奖励、最大清算比例等可在金库层配置。

## 技术难点
- 计息精度与累计（防止舍入套利）
- 抵押品价格波动下健康因子的实时计算
- 清算状态机在预言机异常 / 清算失败 / 重入等场景的异常处理
